# Calculator GitHub Pages

Files:
- `index.html` — website
- `style.css` — fullscreen calculator design
- `script.js` — calculator, music and synced lyrics
- `equals.mp3` — your music file
- `lyrics.txt` — your lyric lines

## Important

Put your existing `equals.mp3` and `lyrics.txt` in this same folder, next to `index.html`.

The lyrics are matched to the timestamps from the original Pygame version.
